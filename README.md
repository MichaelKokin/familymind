# FamilyMind

Локальный прототип пространства семейного исследования: Canvas, люди, документы, источники, утверждения и проверка предложенных связей. Интерфейс на русском.

Этот репозиторий содержит код, вымышленные примеры и техническую документацию. Настоящих семейных данных, переписки, рабочих сессий и внутренних продуктовых материалов здесь нет. Приложение не развёрнуто как публичный сервис.

## Запуск синтетического демо

Нужен Node.js >=20.19. Проверяемая конфигурация: Node 20.20.0 и версии из `package-lock.json`.

```bash
npm ci
npm run dev
```

Откройте http://127.0.0.1:3000. Вымышленная семья, редактор, оригиналы документов, отдельные статусы доказательств и review, сохранение IndexedDB, JSON export/import работают локально. Данные браузера могут быть удалены; сохраняйте экспорт. Настоящие материалы в этот режим не добавляйте.

Production-запуск: `npm run build`, затем `npm start`. Сервер слушает только `127.0.0.1`, а не локальную сеть.

## Частный локальный режим

Код также содержит `/case`, `/case/explore` и `/case/members`. Он требует отдельно подготовленного дела вне checkout и одноразового входа. Пустой clone не содержит личного дела. Для существующего локального дела используйте `npm run case:launch` на macOS либо `npm run case:open` при работающем сервере.

Доступны анализ выбранных материалов через установленный Codex с текущим входом ChatGPT, ответы с источниками и локальные личные/семейные заметки. Новый API-ключ не подключается. Внешний поиск из приложения сейчас недоступен. Частный канвас редактируется владельцем поверх неизменяемого подготовленного среза: близкие с явной связью, материалы с оригиналами, сохраняемая композиция, экспорт/импорт, компактный помощник и ручной операторский маршрут находки без имитации автоматического поиска (см. `docs/PRIVATE_EXPLORE.md`). Это не завершённый многопользовательский пилот.

## Проверки

```bash
npm run lint
npm test
npm run typecheck
npm run build
npm run test:private
npm run test:e2e -- --reporter=line
```

Private E2E создаёт временное синтетическое хранилище, использует подставной CLI вместо модели и порт 3001. M0 E2E использует порт 3002. Реальные дела и рабочий сервер 3000 не используются тестами. Перед сборкой учитывайте уже запущенный production: после пересборки `.next` ему нужен перезапуск.
