# Публичная версия · 8 ноября 2026

Код содержит две отдельные части: синтетический M0 с редактором и локальный частный режим с авторизацией, подготовленным графом, чатом Codex и кабинетами заметок. Частные данные не входят в репозиторий.

Работает: редактирование M0, сохранение IndexedDB, проверка доказательств, JSON round-trip; серверные ревизии частного дела, одноразовый вход, owner-only исследование/чат, личные и семейные заметки с отзывом доступа. В коде есть переход от владельца к предкам с явными родительскими связями и редактируемое личное пространство владельца (близкие, материалы с оригиналами, композиция, экспорт/импорт, зацепки и кандидаты находок в ручном операторском режиме, помощник с чатом) поверх неизменяемого подготовленного среза.

Ограничения: записи подготовленного среза не редактируются из приложения; автоматический внешний поиск недоступен; общего импорта всех частей пространства (заметки, чат) нет; локальный режим не является удалённым многопользовательским M1. Шифрование диска, внешние резервные копии и полноценное восстановление аккаунтов этим приложением не предоставляются.
