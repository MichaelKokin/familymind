# Приватный отчёт исследования

`scripts/render-research-report.mjs` создаёт самостоятельный HTML из подготовленного JSON. Он не ищет данные, не вызывает модель и не меняет дело. Настоящие входные JSON, изображения и результат держат вне checkout. Текст не интерпретируется как HTML; источники привязываются через проверяемые ID, внешние ссылки допускают только HTTP(S) без встроенных логинов.

```bash
node scripts/render-research-report.mjs \
  --input /absolute/private/report-input.json \
  --output /absolute/private/reports/CASE_ID.html \
  --image-root /absolute/private/research
```

Папка `reports` должна находиться в том же private root, что `cases` и `auth`. Имя результата — точный ID существующего дела. Параметр `--image-root` нужен только при наличии `localImage`; путь изображения может быть относительным к этому корню или абсолютным внутри него. Изображения PNG/JPEG/WebP проверяются по сигнатуре, ограничены 8 MiB и включаются исходными байтами; SVG и ссылки вне корня отклоняются. Водяные знаки не изменяются. Максимальный входной JSON — 4 MiB, HTML — 20 MiB. Запись HTML атомарная, файл0600; существующий отчёт по явно указанному пути заменяется только после успешной полной генерации. Не направляйте результат на единственную копию исходного документа.

Контракт JSON (строки могут содержать неопределённые даты; они не нормализуются):

```json
{
  "title": "Синтетический пример",
  "generatedAt": "6 ноября 2026",
  "summary": ["Основной вывод и его ограничения."],
  "findings": [{"title":"Находка","text":"Описание","status":"single-source","sourceIds":["s1"]}],
  "people": [{"id":"p1","name":"Вымышленный Персонаж","dates":"около1900","relation":"Исследуемый человек","note":"Только учебные данные"}],
  "relationships": [],
  "timeline": [{"date":"около1900","title":"Условное событие","text":"Дата требует проверки","sourceIds":["s1"]}],
  "sources": [{"id":"s1","title":"Учебный источник","url":"https://example.test/document","locator":"Лист1","kind":"synthetic"}],
  "branches": [{"title":"Учебная ветвь","status":"unresolved","text":"Открытый вопрос"}],
  "questions": [{"title":"Проверить дату","why":"Один источник","nextStep":"Сопоставить с оригиналом"}],
  "coverage": {"searched":["Учебный набор"],"notSearched":["Настоящие архивы"],"limitations":["Демонстрация"],"counts":{"Источники":1}},
  "conflicts": []
}
```

Необязательные связи имеют форму `{from,to,label,status,sourceIds}`; `from`/`to` должны ссылаться на переданных людей. Они показываются только как явно переданные утверждения. Необязательные конфликты: `{title,variants:[{text,sourceIds}],note}`. Источники могут дополнительно содержать `localImage`. Дубли ID и неизвестные ссылки приводят к отказу; невалидный URL показывается без активной ссылки. Известные коды статусов получают русскую подпись, остальные значения отображаются буквально; исходное значение сохраняется в title. Генератор не присваивает историческую истинность.

Кнопка «Отчёт исследования» открывает `/api/private/report`. Маршрут требует `LocalCaseAccess` через `loadOwnedCase`, выбирает файл исключительно по ID авторизованного дела и игнорирует пользовательские параметры пути. Файлы и каталог `reports` не могут быть символическими ссылками. Нет отчёта — понятный HTML404; нет сеанса — HTML401 без приватных сведений. Ответы `private,no-store`, без Referer; CSP запрещает скрипты, объекты, формы, внешние ресурсы и встраивание страницы в чужой frame. Картинки разрешены только `data:`. Заголовки HTTP ограничивают и вручную изменённый HTML, но это не формат для приёма произвольных загруженных пользователями страниц.

`tests/research-report.test.ts` проверяет экранирование, опасные ссылки, неизвестные ID, точное включение байтов изображения, ограничения путей, запрет записи в checkout, авторизацию, выбор своего дела, размер, symlink и читаемые ошибки. Тесты используют только временные синтетические данные. Генерация отчёта не закрывает требования многопользовательского M1.
