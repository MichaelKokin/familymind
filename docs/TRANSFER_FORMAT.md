# Локальный перенос M0 · схема 1

Функции: `exportPackage` / `importPackage` в `src/data/transfer.ts`. Runtime-схема и проверка связей: `src/domain/model.ts`.

```json
{
  "format": "family-mind",
  "version": 1,
  "exportedAt": "2026-11-06T00:00:00.000Z",
  "omittedFiles": [],
  "workspace": {
    "schemaVersion": 1,
    "id": "workspace_example",
    "title": "Вымышленный пример",
    "synthetic": true,
    "revision": 0,
    "updatedAt": "2026-11-06T00:00:00.000Z",
    "people": [], "sources": [], "artifacts": [], "claims": [],
    "relationships": [], "evidence": [], "reviews": [],
    "questions": [], "runs": [], "positions": {}
  }
}
```

Каждый исходный файл находится в `artifacts[].dataUrl` как base64; metadata включает MIME, размер, имя, sourceId, отдельную transcription и exportAllowed. У неразрешённого к переносу файла dataUrl становится null, а ID попадает в omittedFiles. Метаданные и доказательные ссылки сохраняются. Получатель видит отсутствие файла. `exportAllowed` — локальное заявление пользователя, не юридическая проверка прав.

Предел JSON — 32 МиБ, отдельного файла — 5 МиБ, всех байтов файлов — 20 МиБ. Лимит пакета учитывает base64 и metadata. Вход проходит strict schema, контроль уникальных ID, ссылок на сущности/вложения, статусов доказательств, журналов решений, MIME/сигнатур/размеров и безопасных имён. Неизвестная версия или повреждение отклоняются до транзакции. Файл с флагом synthetic=true не становится проверенно искусственным: пользователь обязан не вводить реальные сведения в M0.

Импорт не объединяет проекты. Он заменяет один активный проект после проверки и явного нажатия. Сначала экспортируйте нужное состояние. Содержимое сущностей и файлов сохраняется при round-trip; revision и updatedAt обновляются на локальной записи. Позиции Canvas отдельны от фактов.

Этот формат не GEDCOM и не CSV-адаптер upstream. Миграции между версиями ещё не реализованы. Для M1 потребуется серверная проверка прав на каждый объект и файл, staging и отдельный протокол экспорта/удаления.
